# i3

X11 session with picom, rofi and betterlockscreen, Gruvbox dark. Installed by the default `./install.sh`. Pick **i3** in the SDDM session menu.

## Keys

| Key | Action |
|-----|--------|
| `Mod+Enter` | Alacritty |
| `Mod+d` | Rofi launcher |
| `Mod+Shift+q` | Close window |
| `Mod+Shift+s` | Screenshot (Flameshot) |
| `Mod+c` | Clipboard (CopyQ) |
| `Mod+x` | Lock |
| `Mod+1-0` | Switch workspace |

## Files

| Path | Installed to |
|------|--------------|
| `configs/i3/config` | `~/.config/i3/config` |
| `configs/i3/Wallpapers/` | `~/.config/i3/Wallpapers/` |
| `configs/picom/picom.conf` | `~/.config/picom/` |
| `configs/rofi/config.rasi` | `~/.config/rofi/` |
| `configs/betterlockscreen/betterlockscreenrc` | `~/.config/betterlockscreen/` |
| `configs/xdg-desktop-portal/portals.conf` | `~/.config/xdg-desktop-portal/` |
| `home/.xinitrc` | `~/.xinitrc` (sets `GTK_USE_PORTAL=1`) |

## Troubleshooting

| Problem | Fix |
|---------|-----|
| File picker doesn't open | Install `xdg-desktop-portal-gtk`, run `/usr/lib/xdg-desktop-portal --replace &`, or log in again |
| Flatpak Qt app picker broken | Install `xdg-desktop-portal-kde` |
